# RUN ROUTE

탄천자전거도로와 보행로를 기준으로 네 가지 러닝 경로를 비교하는 정적 웹 앱입니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

## 경로 유형

- **탄천자전거도로 필수**: 탄천자전거도로의 진입점·중간점·이탈점을 경유합니다. 탄천까지 우회할 수 있습니다.
- **자동차 없는 길**: 보행로·산책로·자전거도로를 우선하고 일반도로를 강하게 회피합니다.
- **최단거리**: 보행 가능한 경로 중 거리를 우선합니다.
- **반반 혼합**: 안전성과 거리·연결성을 균형 있게 선택합니다.

탄천 필수 경로는 Overpass에서 탄천 자전거도로 geometry를 조회한 뒤 BRouter에 경유점으로 전달합니다. Overpass 또는 BRouter를 사용할 수 없으면 경로를 안내하지 않고 다시 시도할 수 있습니다.

지도는 © OpenStreetMap contributors 데이터를 사용하고 Leaflet으로 표시합니다. 주소 검색은 Photon·ArcGIS, 경로 계산은 BRouter 무료 공개 서비스를 저빈도로 사용합니다. 위치와 검색 기록은 저장하지 않습니다.

지도 데이터와 실제 공사·침수·통제 상태가 다를 수 있습니다. 하천변, 교량, 지하통로, 자전거 겸용도로에서는 현장 상태를 확인하고 안전하게 통행하세요.
